# Sony Bulb Controller (Android)

This is a minimal Android app that connects to a Sony camera running the
Camera Remote API and sends bulb commands with a configurable shot count,
exposure time, and interval.

## Prerequisites

- Android SDK installed (Android Studio or command-line tools).
- `ANDROID_SDK_ROOT` or `ANDROID_HOME` set to your SDK path.
- A device or emulator (for testing), and `adb` on your PATH.

## Build a debug APK

```bash
cd android_app
gradle wrapper --gradle-version 8.2
./gradlew assembleDebug
```

Note: the Gradle wrapper JAR is generated by the `gradle wrapper` command and
is not checked into this repository.

The APK is written to:

```
android_app/app/build/outputs/apk/debug/app-debug.apk
```

## Install on a device

```bash
adb install -r app/build/outputs/apk/debug/app-debug.apk
```

## Usage

1. Connect your phone to the camera Wi‑Fi (A7III default: `192.168.122.1`).
2. Open the app and fill in:
   - Number of shots
   - Exposure time (seconds)
   - Interval between shots (seconds)
3. Tap **Start Bulb Sequence**.

If your camera uses a different IP, override the IP field.
